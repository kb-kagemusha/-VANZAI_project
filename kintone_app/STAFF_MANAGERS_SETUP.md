# クライアント責任者・クライアント担当者登録マスタ アプリ設定ガイド

## 概要
このアプリは、案件のクライアント責任者とクライアント担当者を一元管理するマスタアプリです。
案件登録画面でクライアント責任者・クライアント担当者をドロップダウンから選択できるようになります。

## セットアップ手順

### 1. Kintoneアプリの作成
1. Kintoneのゲストスペース（ID: 3）にログイン
2. 新しいアプリを作成
3. 「ファイルから作成」を選択
4. `staff_managers_sjis.csv` をアップロード

### 2. フィールド定義
以下のフィールドが自動的に作成されます：

| フィールドコード | フィールド名 | タイプ | 必須 | 説明 |
|----------------|------------|--------|------|------|
| staff_id | 社員ID | 文字列（1行） | ○ | STM001形式の自動採番ID |
| client_company | クライアント企業 | ドロップダウン | ○ | クライアントマスタ（App167）の企業名から選択 |
| name | 氏名 | 文字列（1行） | ○ | クライアント責任者・担当者の氏名 |
| role | 役割 | ラジオボタン | ○ | クライアント責任者/クライアント担当者 |
| phone | 電話番号 | 文字列（1行） | - | 連絡先電話番号 |
| email | メールアドレス | 文字列（1行） | - | 連絡先メールアドレス |
| is_active | 有効フラグ | ドロップダウン | ○ | 有効/無効（デフォルト：有効） |
| notes | 備考 | 文字列（複数行） | - | その他メモ |

**重要**: `client_company` フィールドは、クライアントマスタ（App167）の `client_name` フィールドから企業名を取得して選択肢として表示されます。front_dashboard.jsのカスタマイズにより自動的に連動します。

### 3. アプリIDの設定
アプリIDは **309** に設定してください：

1. 作成したアプリのURLから現在のアプリIDを確認
2. アプリ設定 > 一般 > アプリIDを309に変更
3. 保存して公開

**注意**: アプリIDが309以外の場合、`front_dashboard.js` のCONFIG.apps.staff_managersを実際のアプリIDに変更する必要があります。

### 4. クライアントマスタとの連携設定
`client_company` フィールドは、クライアントマスタ（App167）と連動します。

#### 前提条件
- クライアントマスタ（App167）が作成・公開されていること
- クライアントマスタのフィールドコード `client_name` に企業名が登録されていること

#### 連携の仕組み
1. クライアント職員登録画面を開くと、`client_company` ドロップダウンが自動的に生成されます
2. App167から `client_name` フィールドの値を取得し、選択肢として表示
3. 選択したクライアント企業は、案件登録画面で職員を絞り込む際に使用されます

#### 確認手順
1. クライアントマスタ（App167）にクライアント企業が登録されていることを確認
2. クライアント職員登録画面（App309）で「クライアント企業」ドロップダウンを確認
3. クライアント企業の選択肢が表示されることを確認

### 5. アクセス権限の設定
1. アプリ設定 > アクセス権 を開く
2. 案件管理を行うユーザー/グループに「レコード追加・編集」権限を付与
3. マスタ管理者には「アプリ管理」権限のみ付与（アプリ設定は管理者のみ）
4. 保存して公開

### 6. サンプルデータの追加
`staff_managers_sjis.csv` に含まれるサンプルデータ：
- STM001: 山田太郎（クライアント責任者）
- STM002: 佐藤花子（クライアント担当者）
- STM003: 鈴木一郎（クライアント責任者）
- STM004: 田中美咲（クライアント担当者）
- STM005: 高橋健太（クライアント責任者）

必要に応じて、実際の社員情報に置き換えてください。

## 利用方法

### 新しいクライアント責任者・担当者の登録
1. クライアント責任者・クライアント担当者登録マスタアプリを開く
2. 「+」ボタンで新規レコードを追加
3. 必要な情報を入力
4. 「保存」をクリック

### 案件登録での使用
1. ダッシュボードから「案件を登録」をクリック
2. 「クライアント責任者」と「クライアント担当者」のドロップダウンに、有効なクライアント責任者・担当者が表示されます
3. 選択して案件を登録

## 注意事項
- 「is_active」が「無効」に設定されているクライアント責任者・担当者は、ドロップダウンに表示されません
- ドロップダウンはアルファベット順（staff_id順）で表示されます
- クライアント責任者・担当者を削除する代わりに、「is_active」を「無効」に設定することを推奨します

## トラブルシューティング

### クライアント企業の選択肢が表示されない
1. クライアントマスタ（App167）にクライアント企業が登録されているか確認
2. App167のフィールドコード `client_name` に企業名が入力されているか確認
3. ブラウザのコンソール（F12）でAPIエラーを確認
   - `[DEBUG] App167から取得したクライアント数:` のログで件数を確認
   - `[DEBUG] client_name:` のログで企業名が表示されるか確認
4. クライアントマスタへのアクセス権限があるか確認

### ドロップダウンにクライアント責任者・担当者が表示されない
1. アプリIDが正しく設定されているか確認（App309）
2. `is_active` フィールドが「有効」になっているか確認
3. ブラウザのコンソール（F12）でエラーメッセージを確認

### エラー: 「クライアント責任者・クライアント担当者マスタが見つかりません」
- CONFIG.apps.staff_managers のアプリIDが正しいか確認（309であること）
- 該当アプリへのアクセス権限があるか確認
- アプリが公開されているか確認

### 案件登録で職員が連動しない**`name`** と完全一致しているか確認（大文字小文字、スペースなど）
3. front_dashboard.jsが正しくアップロードされ、適用されているか確認
4. ブラウザのコンソール（F12）で以下のログを確認：
   - `[DEBUG 案件登録] App167から取得したクライアント数:`
   - `[DEBUG 案件登録] App309から取得した職員数:`
   - `[DEBUG 案件登録] staffByClientマップ:` で連動が正しく設定されているか正しいクライアント企業名が入力されているか確認
2. クライアント企業名がApp167の `client_name` と完全一致しているか確認（大文字小文字、スペースなど）
3. front_dashboard.jsが正しくアップロードされ、適用されているか確認
