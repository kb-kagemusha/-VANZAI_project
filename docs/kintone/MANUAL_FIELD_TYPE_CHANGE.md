# Kintone フィールドタイプ手動変更ガイド

## 問題
API経由でDROP_DOWN/RADIO_BUTTON → SINGLE_LINE_TEXT への変換ができない

エラー: "フィールド「xxx」に指定したフィールドタイプが正しくありません"

## 原因
Kintone API は選択肢付きフィールド→文字列への直接変換を許可していない

## 解決策：手動でフィールドタイプを変更

### workers アプリ (ID: 165)

1. **アプリ設定を開く**
   - https://xtf5wpxp3gk2.cybozu.com/k/guest/3/165/
   - 右上の⚙️（設定）→「設定」→「フォーム」

2. **以下のフィールドを変更**：

   | 現在のフィールド名 | フィールドコード | 変更前タイプ | 変更後タイプ |
   |-----------------|--------------|------------|------------|
   | worker_id | worker_id | ドロップダウン | 文字列（1行） |
   | name | name | ドロップダウン | 文字列（1行） |
   | phone | phone | ドロップダウン | 文字列（1行） |

3. **変更手順（各フィールド）**：
   - フィールドをクリック
   - 「フィールドタイプを変更」
   - 「文字列（1行）」を選択
   - 「保存」

4. **アプリを更新**を押す


---

## 代替案：CSV インポート

手動変更が面倒な場合は、CSV インポートを使用：

1. DBデータをCSVエクスポート
2. Kintone UI で「ファイルから読み込む」
3. フィールド対応を設定
4. インポート実行

---

## 補足：なぜAPI変換できないのか

Kintone API の制約：
- 選択肢を持つフィールド（ドロップダウン/ラジオボタン）は、既存の選択肢データとの整合性を保つため、API経由での文字列変換を許可していない
- UI経由での変更のみ可能（内部で適切なマイグレーション処理が行われる）
