# 案件種別マスタ（App164）セットアップ手順

## 問題
App164に`category_level`、`parent_major`、`parent_middle`フィールドが存在せず、既存の`type_id`と`name`が選択肢フィールドとして設定されています。

## 解決策：手動セットアップ

### 1. App164のフィールド設定を変更

1. Kintoneにログイン
2. 案件種別マスタ（App164）を開く
3. 右上の⚙（設定）→ フォーム を開く

### 2. 必要なフィールドを追加/修正

#### 既存フィールドの修正
- **type_id**: 選択肢 → **文字列（1行）** に変更
- **name**: 選択肢 → **文字列（1行）** に変更

#### 新規フィールドを追加
以下の3つのフィールドを追加：

| フィールドコード | フィールド名 | タイプ | 必須 |
|---|---|---|---|
| category_level | カテゴリレベル | 文字列（1行） | ✓ |
| parent_major | 親（大カテゴリ） | 文字列（1行） | |
| parent_middle | 親（中カテゴリ） | 文字列（1行） | |

### 3. アプリを更新して保存

### 4. 既存レコードを削除
- アプリの一覧画面で全レコードを選択
- 削除ボタンで削除

### 5. CSVをインポート

1. 右上のメニューから「ファイルから読み込む」を選択
2. `kintone_app/project_types_sjis.csv` を選択
3. **文字コード**: UTF-8 を選択
4. フィールドマッピングを確認:
   - type_id → type_id
   - name → name
   - category_level → category_level
   - parent_major → parent_major
   - parent_middle → parent_middle
5. インポート実行

### 6. front_dashboard.jsをアップロード

1. Kintoneのポータル画面を開く
2. 右上の⚙（設定）→ JavaScript / CSSでカスタマイズ
3. `kintone_app/customizations/front_dashboard.js` をアップロード
4. 保存

### 7. 動作確認

1. 案件アプリ（ID: 160）を開く
2. 「案件を登録」ボタンをクリック
3. 大カテゴリを選択
4. 中カテゴリが動的に絞り込まれることを確認
5. 小カテゴリが動的に絞り込まれることを確認

## カテゴリ階層構造

**合計: CSV件数（2026-02-07時点は127件）**

## トラブルシューティング

### エラー: フィールドが見つからない
→ 手順2のフィールド追加を確認

### エラー: 選択肢にない
→ type_idとnameを文字列フィールドに変更

### カスケードが動作しない
→ 親子関係（parent_major/parent_middle）が正しく設定されているか確認

### ブラウザコンソールでエラー
→ F12でコンソールを開き、`loadCategoryData`のエラーメッセージを確認
