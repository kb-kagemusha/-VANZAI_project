# 案件種別マスタセットアップ - クイックスタート

## 🎯 目標
App164のカテゴリデータを登録し、フロントページで動的カスケード選択を実現
（件数は運用で変動。2026-02-07時点の実データは127件）

## ⚡ 5分でセットアップ

### STEP 1: App164のフィールド設定（2分）

1. Kintoneにログイン: https://xtf5wpxp3gk2.cybozu.com
2. ゲストスペース(3) → 案件種別マスタ(164) を開く
3. 右上の⚙ → 「設定」→「フォーム」をクリック

#### 既存フィールドの変更
- **type_id**: ドロップダウンの設定アイコンをクリック → 「フィールドタイプを変更」→「文字列（1行）」→ 必須☑ → 保存
- **name**: 同様に「文字列（1行）」に変更 → 必須☑ → 保存

#### 新規フィールドの追加
右側から「文字列（1行）」を3回ドラッグ&ドロップし、以下を設定:

| フィールドコード | フィールド名 | 必須 |
|---|---|---|
| category_level | カテゴリレベル | ☑ |
| parent_major | 親（大カテゴリ） | □ |
| parent_middle | 親（中カテゴリ） | □ |

4. 右上「フォームを保存」→「アプリを更新」→ 完了

---

### STEP 2: マスタデータ登録（1分）

PowerShellで実行:
```powershell
python scripts/upload_project_types.py
```

**成功メッセージ（例）:**
```
✅ データ登録完了!
  合計: (CSV件数)
```

---

### STEP 3: フロントページJS更新（1分）

1. Kintone → ポータル画面を開く
2. 右上⚙ → 「JavaScript / CSSでカスタマイズ」
3. `kintone_app/customizations/front_dashboard.js` をアップロード
4. 保存

---

### STEP 4: 動作確認（1分）

1. 案件アプリ(160) を開く
2. 「案件を登録」ボタンをクリック
3. **大カテゴリ**を選択 → **中カテゴリ**が動的に絞り込まれる ✓
4. **中カテゴリ**を選択 → **小カテゴリ**が動的に絞り込まれる ✓

---

## ❌ トラブルシューティング

### エラー: 「選択肢にありません」
→ STEP 1のフィールド型変更が未完了  
→ type_idとnameを文字列型に変更してください

### エラー: 「フィールドが見つかりません」
→ STEP 1の新規フィールド追加が未完了  
→ category_level, parent_major, parent_middleを追加してください

### カスケードが動作しない
→ ブラウザのコンソール(F12)でエラーを確認  
→ `loadCategoryData` のエラーメッセージを確認
