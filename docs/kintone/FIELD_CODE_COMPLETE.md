## 残っている問題

❌ **ドロップダウンとラジオボタンに選択肢制限が残っている**

エラー例:
```
"errors": {
  "records[0].name.value": {"messages": ["\"山田太郎\"は選択肢にありません。"]}
}
```

**原因**: フィールドコードは変更できたが、フィールドタイプは変更できなかった
- DROP_DOWN（選択肢制限付き）のまま
- RADIO_BUTTON（選択肢制限付き）のまま

**必要な対応**: 選択肢を空にするか、フィールドタイプを変更

## 対応方法（3つの選択肢）

### 方法1: Kintone UIで選択肢を削除（推奨・5分）

各アプリで手動で選択肢を削除します。

**手順（各アプリで実施）:**

1. Kintoneアプリを開く
2. 「設定」→「フォーム」
3. 各フィールドをクリック

#### Workers (165)
- **worker_id** (ドロップダウン): 「選択肢」タブ→全選択肢を削除→保存
- **name** (ドロップダウン): 同上
- **phone** (ドロップダウン): 同上
- **is_active** (ラジオボタン): 選択肢を「有効」「無効」のみ残す

#### Clients (167)
- **client_id** (ラジオボタン): 選択肢を全削除
- **name** (ラジオボタン): 選択肢を全削除
- **code** (ラジオボタン): 選択肢を全削除
- **address** (ラジオボタン): 選択肢を全削除

#### Sites (166)
- **site_id** (ドロップダウン): 選択肢を全削除
- **name** (ドロップダウン): 選択肢を全削除
- **code** (ドロップダウン): 選択肢を全削除
- **address** (ドロップダウン): 選択肢を全削除

#### Roles (163)
- **role_id** (ラジオボタン): 選択肢を全削除
- **name** (ラジオボタン): 選択肢を全削除
- **description** (ラジオボタン): 選択肢を全削除

#### Project Types (164)
- **type_id** (ラジオボタン): 選択肢を全削除
- **name** (ラジオボタン): 選択肢を全削除
- **description** (ラジオボタン): 選択肢を全削除

4. 「保存」→「アプリを更新」

**完了後:**
```bash
python scripts/sync_db_to_kintone.py all
```
