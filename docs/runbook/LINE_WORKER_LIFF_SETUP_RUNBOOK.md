# 稼働者向けLIFFアプリの追加手順（統合計画 ①）

対象：運営（LINE Developers の管理権限を持つ人）
目的：公式LINEから開く稼働者向けのWeb画面（日付を選んでの受諾、Web確認画面）を作るため、LIFFアプリを1つ追加し、その **LIFF ID** を開発に渡す。
関連：統合計画 `docs/ops/LINE_WORKER_ROADMAP_2026-10-22.md` §3・§5 ①、DEC-032（登録用LIFF）、`docs/ops/LINE_REGISTRATION_CONFIG_RUNBOOK.md`

所要時間：10〜15分。料金はかからない。

---

## 0. 最初に必ず確かめること（いちばん大事）

LIFFで本人を確認するとき、LINEが返す本人のID（ユーザーID）は **プロバイダー（LINE Developers で、チャネルをまとめる単位）ごとに違う**。
稼働者の公式LINE（Messaging API のチャネル）と、LIFFを作る LINE Login チャネルが **同じプロバイダー** にないと、LIFFで開いた人が誰なのか照合できない。

登録用の手順書には「2026-10-12 に検証用の LINE Login チャネルを使った」「クライアント用の公式LINEは別」と書かれている。**今の本番の公式LINEと同じプロバイダーに LINE Login チャネルがあるか**を、まず確認する。

1. https://developers.line.biz/console/ にログインする。
2. プロバイダーの一覧から、**稼働者が友だち追加している公式LINE（Messaging API のチャネル）** があるプロバイダーを開く。
   - 見分け方：チャネルの「Messaging API設定」タブのボットのベーシックID（@で始まるID）が、稼働者に案内している公式LINEのIDと同じもの。
3. 同じプロバイダーの中に **LINE Login チャネル** があるか見る。
   - **ある** → そのチャネルを使う（§1へ）。登録用のLIFFが入っているチャネルなら、それが最適。
   - **ない** → 同じプロバイダーの中に LINE Login チャネルを新しく作る（§0-a）。
   - 公式LINEと別のプロバイダーにしか LINE Login チャネルがない場合、そこに作っても本人の照合ができない。**別のプロバイダーには作らない**。

### 0-a. LINE Login チャネルを新しく作る場合（同じプロバイダーに無いときだけ）

1. 公式LINEがあるプロバイダーを開き、「新規チャネル作成」→「LINEログイン」。
2. 入力：
   - 会社・事業者の所在国：日本
   - チャネル名：例「VANZAI 稼働者」
   - チャネル説明：例「稼働者向けの予定確認・参加日の選択」
   - アプリタイプ：**ウェブアプリ**
   - メールアドレス：運営の連絡先
3. 規約に同意して作成。
4. 作成したチャネルの「チャネル基本設定」にある **チャネルID**（数字）を控える（§3で渡す）。

---

## 1. LIFFアプリを追加する

1. §0で決めた LINE Login チャネルを開き、「LIFF」タブ →「追加」。
2. 次のとおり入力する。

| 項目 | 入力する値 |
|---|---|
| LIFFアプリ名 | `VANZAI 稼働者` |
| サイズ | **Full** |
| エンドポイントURL | `https://vanzai-portal.com/public/line-worker` |
| Scope | **openid** にチェック（本人の確認に使う）。profile は不要 |
| ボットリンク機能 | **On (Normal)**（公式LINEの友だち追加を案内できるように） |
| Scan QR | オフ |
| モジュールモード | オフ |

3. 「追加」を押す。
4. 一覧に出た **LIFF ID**（`1234567890-AbCdEfGh` の形）を控える。

**注意**
- エンドポイントURLの画面（`/public/line-worker`）は、①の実装で作る。作る前に開いても「ページが見つからない」になるが、LIFFの追加は先にしてよい。
- 登録用のLIFF（エンドポイント `/public/line-registration`）は**変えない**。新しく1つ追加する。
- チャネルが「開発中」のままだと、チャネルの管理者として登録した人しかLIFFを開けない。試験運用の3〜4人に使ってもらう前に「公開済み」にする（§4）。

---

## 2. 確認

LIFFアプリの一覧に次の2つが並んでいればよい（登録用LIFFが同じチャネルにある場合）。

| LIFFアプリ名 | エンドポイントURL |
|---|---|
| （登録用） | `https://vanzai-portal.com/public/line-registration` |
| VANZAI 稼働者 | `https://vanzai-portal.com/public/line-worker` |

---

## 3. 開発に渡すもの

秘密情報（チャネルシークレット等）は渡さない。次の3つだけ。

1. **LIFF ID**（§1の4）
2. **LINE Login チャネルのチャネルID**（数字。登録用と同じチャネルなら「登録用と同じ」で可）
3. §0の確認結果：「公式LINEと同じプロバイダーにある」かどうか

開発側は、サーバーの追加設定ファイル（git管理外。`.env` は変更しない）に LIFF ID を入れ、①の実装の最初に、**検証用のLINEで「LIFFで得た本人のID」と「公式LINEのWebhookで届く本人のID」が一致すること**を確認する。一致しなければ①は進めず、§0をやり直す。

---

## 4. 公開の前に（試験運用の前）

- LINE Login チャネルを「開発中」から「**公開済み**」にする（チャネル画面の上部）。公開済みにしないと、試験運用の人がLIFFを開けない。
- 公開済みにしても、リッチメニューやトークから案内しない限り、稼働者がこの画面にたどり着くことはない（画面の公開は、統合計画の「機能ごとの公開・停止」で管理する）。

---

## 5. 戻すとき

- LIFFアプリを削除すれば、その画面は開けなくなる。登録用のLIFF・公式LINEのトーク・①⑤⑥のボタンには影響しない。
- 稼働者の連携・予定のデータは消えない。
