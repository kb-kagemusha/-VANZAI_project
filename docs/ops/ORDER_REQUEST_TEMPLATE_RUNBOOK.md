# 発注依頼書のテンプレート（Ver.0.49.4 / DEC-072・077・078）

目的は、月例・季節・年次・不定期の同じようなイベントで、過去の依頼書を探さず内容を再利用すること。

案件名には名称、参考URLにはイベント等のURL（任意）を別々に入力する。参考URLもテンプレートに保存される。稼働場所は会場名を入力し、住所は「稼働場所の住所」に入力する。郵便番号7桁で町域まで補完した後、番地・建物名を追記する。入力済み住所がある場合は候補を選んだときだけ置き換える。取得できない場合は住所を直接入力する。依頼書として確定するときは案件名が必須。

## 保存する

### テンプレートを直接作成する

1. 発注依頼書の画面上部で「テンプレートの作成」を押す。
2. テンプレート名（必須）と、案件名・カテゴリ・発注元・稼働場所・時刻・単価・内容・持ち物・インセンティブ条件・連絡担当・メモなどの再利用する内容を入力する。未定の内容は呼び出し後に補える。
3. 「テンプレートを作成」を押す。「保存済みテンプレート」に「直接作成」として表示される。

日付・休業日・回答期限・送付先はこの画面で入力しない。テンプレートの保存だけでは依頼書・文書番号・PDF・送付記録を作らない。呼び出した後に日付・期限・送付先を設定して通常の依頼書を作成する。

### 作成済みの依頼書から保存する

1. 発注依頼書の「作成した依頼書」で、再利用したい行の「テンプレートとして保存」を押す。
2. 「駅前イベント・通常」「年末調査」など、探しやすい名前を付けて「テンプレートを保存」を押す。
3. 保存対象はその版の保存済み内容。編集中の未保存内容は、先に下書きへ保存してから登録する。

テンプレート名は有効なものの間で重複できない。前後の空白、英字の大文字・小文字や全角・半角をそろえて判定する。

## 呼び出す

1. 「新規の依頼書を作成」→「テンプレートから呼び出す」を押す。「保存済みテンプレート」から直接始めることもできる。
2. 名前で検索し「このテンプレートで新規作成」を押す。
3. 稼働日、各勤務・単価グループの日付、休業日、回答期限、送付先を今回の内容で設定する。
4. 会場・発注元・担当者・勤務時刻・単価・内容も確認する。特に前年の単価が今年も有効か、文章に古い日付が残っていないかを確認する。
5. 通常どおり下書きを保存し、PDFを確認して送付する。

呼び出しただけでは依頼書を保存・確定・送付しない。元の依頼書の受諾・予定を変更する「変更を作成」とは別の操作。
呼び出した内容を編集しても、保存済みテンプレートは変わらない。元の依頼書を後から変更・一覧除外してもテンプレートは変わらない。

## 内容を入れ替える・整理する

不要なものは「保存済みテンプレート」の「一覧から外す」で非表示にする。データと監査ログは残る。
内容を更新する場合は「テンプレートの作成」から新しく保存するか、新しい内容の依頼書を保存したうえで別名でテンプレートを保存する。同じ名前を使いたい場合は古いテンプレートを一覧から外してから保存する。
保存と一覧除外は「発注依頼書の操作」権限が必要。閲覧には「発注依頼書の閲覧」権限が必要。

## LINEの参加日選択

選択画面は、依頼された選択可能日を初めからすべて選んだ状態。休業日・個人に設定した不参加日は選べない。
本人は行けない日をタップして外し、「確認する」で参加日・不参加日を確認して「送信」する。月をまたぐ場合もすべての提示日が初期選択される。
全日を外すと送信できない。全日辞退の場合はLINEの「今回は辞退します」を使用する。
