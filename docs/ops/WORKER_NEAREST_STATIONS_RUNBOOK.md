# 稼働者の最寄り駅を複数登録する

対象: Ver.0.45.7以降。仕様: DESIGN_SPEC_v0.3 §6.1 / DEC-050。

1. 管理画面の「稼働者登録・一覧」から新規登録または編集を開く。本人が公式LINEから登録・更新する場合も同じ操作。
2. 従来の最寄り駅・徒歩時間に1駅目を入力する。既存登録の1駅目はそのまま表示される。
3. 「＋ 最寄り駅を追加」で2駅目以降を追加する。追加駅の駅名は100文字以内、徒歩時間は任意（0〜300分の整数）。完全な空欄行は保存しない。
4. 追加駅を減らす場合は、その駅の「削除」を押す。1駅だけの利用者は追加操作不要。
5. 管理画面では登録・更新する。LINEでは内容確認後に申請し、管理者が追加駅を含む変更前後を確認して承認する。承認前は既存の登録情報を変更しない。

編集・承認中に別の担当者が駅情報を変更した場合は保存を止める。最新の内容を開き直して確認する。リリース前に開いた画面の比較票も更新が必要になることがある。

更新履歴は `worker_created` / `worker_updated` のprofileおよびLINE承認の監査に保存される。追加駅を送信しない既存API呼び出しでは登録済みの追加駅を保持する。空配列を明示して保存・承認した場合のみ追加駅を削除する。
