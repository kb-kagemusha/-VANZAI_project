# 曜日別の発注と祝日

1. 全体の稼働期間を設定し、稼働日の詳細で「毎週」を選ぶ。月〜日と「祝日」の8つのボタンを押して、その行の時間と報酬を入力する。開始日・終了日は出ない（全体の稼働期間の全部が対象）。期間を細かく区切るときだけ「期間を区切る」にチェックを入れる。
2. 例：月〜金をA、土日をB、祝日をCにするときは、行を3つ作り、1行目に月〜金、2行目に土・日、3行目に「祝日」を押す。祝日は、どこかの行で「祝日」を押していればその行の条件が常に優先される（月〜金や土日の祝日も）。押していなければ、祝日もその日の曜日の行の条件になる。祝日を稼働しない日にする場合は、休業日に設定する。
3. 「祝日一覧を確認」を開き、内閣府CSVの取り込み記録を見る。CSVにある日は確認済みです。CSVより先の年だけ候補なので、追加・除外が必要なら直してから「この一覧を確認して依頼書に反映」を押す。手で追加・除外した日は次の取り込みでも残る。休業日（稼働しない日）は別に設定する。
4. 祝日一覧が変更された場合や条件の期間を変更した場合は、確定前に一覧を確認し直す。確定後の版は確認時の祝日を保持する。取り込み済みの期間が残り3か月を切ったら、画面の案内に従って内閣府のCSVを取り込む。
5. 1人日請求の単価設定で、必要な曜日と祝日の単価を別に入力する。祝日欄を空にした場合は曜日の単価、曜日も空なら基本単価を使う。祝日単価の入力には祝日を確認した曜日別依頼書が必要。確定済み請求書・支払明細・締め済み金額を自動再計算しない。

## 内閣府CSVの取り込み

祝日一覧の正本は内閣府が公開している祝日CSV（https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv）です。祝日一覧の画面から「内閣府の祝日CSVを取り込む」を押すと、取得日時、実行者、取得元、対象期間、件数、前回との増減・名称変更が保存され、監査ログ `holiday_csv_imported` にも残ります。CSVの対象期間内では、手で追加・除外した日以外はこのCSVに合わせます。対象期間より後の年だけ、祝日ライブラリの候補を出します。確定済みの依頼書・請求書・支払明細は取り込みでは変わりません。

## 重なり・漏れ・旧設定

- 同じ曜日（または「祝日」）が期間の重なる2行で押されている場合は赤く知らせ、保存できない。押されていない曜日・祝日（稼働しない日になる）があるときは、保存前に確認が出る。休業日は漏れに数えない。
- 保存済みの旧「毎週」（「祝日もこの条件に含める」を使っていた行）は、旧設定のまま計算・表示される。「新しい設定に切り替える」を押した行だけが新しい規則になる（旧「祝日は対象外」の行は、祝日が稼働日になる確認が出る）。
