# 曜日別の発注と祝日

1. 全体の稼働期間を設定し、稼働日の詳細で「毎週」を選ぶ。開始日・終了日、曜日、時間を設定する。月〜土から祝日を除く条件では月〜土を選び、祝日を含めるチェックは外す。
2. 日曜・祝日用の詳細を追加し、同じ期間、日曜、祝日を含めるチェック、別の時間を設定する。単価を稼働日に合わせる設定で、それぞれの報酬を入力する。
3. 「祝日一覧を確認」を開き、候補を確認する。追加・除外は共通一覧を変更し、操作者と前後の値を監査に残す。「この一覧を確認して依頼書に反映」を押し、日付・条件を確認する。休業日（稼働しない日）は別に設定する。
4. 祝日一覧が変更された場合や条件の期間を変更した場合は、確定前に一覧を確認し直す。確定後の版は確認時の祝日を保持する。将来の祝日は法改正などで変わるため、候補と公式情報を照合する。
5. 1人日請求の単価設定で、必要な曜日と祝日の単価を別に入力する。祝日欄を空にした場合は曜日の単価、曜日も空なら基本単価を使う。祝日単価の入力には祝日を確認した曜日別依頼書が必要。確定済み請求書・支払明細・締め済み金額を自動再計算しない。

## 公式CSVとの年次照合

内閣府の祝日CSVを別途取得し、接続先を確認した `DATABASE_URL` を実行環境に設定してから、`python -m scripts.compare_holiday_csv --year 2027 --csv <CSVのパス>` を実行する。結果は日付の差だけを表示し、DBやCSVを変更しない。CSVの公開範囲と法改正、手動の追加・除外を確認し、変更が必要なら画面から明示操作する。CSVそのものは取り込みの正本にしない。
