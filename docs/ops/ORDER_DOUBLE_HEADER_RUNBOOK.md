# ダブルヘッダーの作成・送付 運用手順（DEC-148、0.59.3〜）

ダブルヘッダー：同じ日の2件（例：朝2時間＋昼3時間）を、稼働者に1件の依頼としてまとめて送り、受諾も辞退も2件まとめて受ける。
案件・依頼書番号・PDF・請求・支払は2件それぞれのまま。

いまは **テスト区分だけ** で作れる。正式区分は、テストで送付→返事→起床確認を確かめてから開ける。

## 作る

1. 発注依頼書 →「新規の依頼書を作成」→「ダブルヘッダー」にチェックを入れる。
2. 「2件の要点」で、稼働日（2件共通の1日）、1件目・2件目の案件名・稼働場所・開始（集合）・終了・単価（日給／時給）を入れる。
3. 「詳細を入力」で下の入力欄を切り替え、それぞれの依頼元・カテゴリ・住所・内容・持ち物などを入れる。入力中の内容は切り替えても消えない。
4. 移動に必要な時間（分）を確かめる。初期値は設定の値（仮の値60分）。初期値を変えるときは「初期値を変更」（作成済みのダブルヘッダーは変わらない）。
5. 「保存」で2件をまとめて保存する（片方だけ保存されることはない）。保存では誰にも送らない。

## 送る

1. 「送付へ進む」→ 期限と送付先を決める（2件で共通）。
2. 「PDFを確認する」→「1件目のPDF」「2件目のPDF」の両方を確かめる。
3. 移動の間隔が移動に必要な時間より短いときは、確認した理由を入れる（監査ログに残る）。時間が重なっているときは送れないので、時間を直す。
4. 「今すぐ送付する」→ 2件が同時に確定し、送付先1人に1通で届く。

## 返事・その後

- 稼働者のボタンは「2件とも受諾します」「2件とも辞退します」。どちらで返事しても2件に同じ返事が記録され、予定表に2行（同じ日）並ぶ。起床確認は早い方の開始時刻が基準。
- 片方を取り消すと、もう片方への返事は受け付けない（稼働者には「運営からの連絡をお待ちください」と返る）。もう片方を続けるかは運営が本人に確認する。
- ダブルヘッダーの依頼書は「変更を作成」「正式版を作成・確認」ができない（後の段階で追加）。内容を変えるときは取り消して作り直す。
- 請求・支払は今までどおり2件それぞれ。
