# LINE登録の追加設定（検証用）

DEC-032/033の承認・紐付けルールを変更しない。2026-10-12のユーザー許可により検証入口を有効にする。一般公開と実在者情報の取得は未承認。今後の変更は毎回ユーザーへ確認する。

APIの起動時に `/var/www/vanzai/line-registration-config.json` を読む。既存の `.env` は編集・表示しない。追加設定はgit管理外で、パーミッションは0600とする。APIの各ワーカーは同じ設定を読み込むため、変更後はAPI再起動が必要。

```json
{
  "LINE_LOGIN_CHANNEL_ID": "LINEログインチャネルのID",
  "LINE_LIFF_ID": "LIFFのID",
  "LINE_WORKER_REGISTRATION_ENABLED": true
}
```

3キー以外や不正な型・形式は許可しない。秘密情報は格納しない。設定ファイルがない場合は既存の環境変数の動作を維持する。ファイルが存在する場合は、この3項目に限り追加設定を優先する。

確認は `/api/health` と `/api/line/registration/entry` を使用する。後者の `enabled` と `liff_id` を確認したあと、LINEアカウントで「登録」を送信し、ボタンから架空情報を入力する。実機のログイン・権限同意は本人が行う。2026-10-12にユーザーが検証用LINEログインチャネルを公開済みに変更し、フォーム表示を確認した。クライアント用公式LINEは別で、今回のサイトは検証用である。

## ロゴ・入力画面・アクセス項目（0.40.0）

利用者が提供したロゴをそのまま使用し、入力・内容確認・受付の3状態を表示する。個人情報の利用目的は入力前に表示する。送信結果が `saved=false` の場合は今回の入力が保存されていないことを示し、新規受付の完了と表示しない。

最寄り駅（100文字以内）と徒歩時間（0〜300分の整数）は任意入力。空欄は既存値を消さず、0分は値として保持する。申請保存後、専用審査で比較して、承認と同じ取引で稼働者の既存列へ反映する。通常編集・LINE承認の比較対象は9項目。旧画面の比較票は不一致で保存を止めるため、必要に応じて最新内容を読み直す。

確認: 新規申請、既存更新、0分、空欄保持、駅情報の競合、再送、本人の変更を試験する。スマートフォンでは古い画面を閉じ、トークで再度「登録」を送り、新しいボタンから開く。入力画面には本人情報を自動表示しない。

利用目的の表示は「稼働者情報の登録・更新、お仕事のご案内および業務連絡」とする。保持期間、削除・匿名化の運用、事業者の正式なプライバシーポリシー等はこの表示変更で確定したものと扱わない。

入口を閉じる場合は、ユーザーの許可を受けて追加設定の `LINE_WORKER_REGISTRATION_ENABLED` を false にし、APIを再起動する。申請、稼働者、既存のLINE紐付けは削除しない。

今回の変更は設定読み込みのみで、業務データの更新・新規の業務監査ログは発生しない。既存のWebhook受付結果・申請送信・審査の監査は従来どおり。

## 住所補完・必須入力・緊急連絡先（0.41.0）

DEC-035により、新規LINE登録では建物名だけ任意とし、それ以外は必須にする。登録済みの更新は変更項目だけ入力する。緊急連絡先を変更する場合は電話番号・お名前・関係の3つを入力する。稼働者一覧の新規登録にも同じ3項目を必須で追加する。

郵便番号の7桁入力で都道府県・市区町村・町域を補完する。番地は利用者が入力する。候補が複数なら選択する。検索中に手入力した住所と建物名は保護し、10秒のタイムアウトや取得失敗後も手入力できる。検索先へ送るのは郵便番号だけ。

フォーム版2の新規申請は追加の必須条件で審査する。既存申請はNULL版のまま従来の条件で審査・再送できる。通常編集とLINE承認は緊急連絡先を含む12項目で比較する。旧画面から保存する場合は最新内容を読み直す。

実機確認は架空情報を使用する。未紐付け本人で新規の必須表示を確認し、紐付け済み本人では任意表示・部分更新を確認する。郵便番号の補完後に番地を追記し、緊急連絡先を確認画面で確認して送信する。管理者の審査では変更前後と、承認後の稼働者一覧の保存内容を確認する。

## 登録済み情報の入力欄表示（0.42.0）

有効なLINE紐付けがある本人には、現在の稼働者情報をフォームに表示する。値が空の入力欄は建物名以外「必須」。氏名とふりがなは保存値が空白区切りのとき姓・名へ分ける。区切りがないときは全文を姓欄に出し、フォームの案内に従って本人に確認して入力してもらう。住所は都道府県が認識できる場合のみ分けて表示する。

送信前に、フォームを開いたときの稼働者情報と現在値が一致することを確認する。不一致のときは申請を作らず、LINEの登録ボタンから画面を開き直して最新情報を読み込む。氏名などの個人情報は画面に表示するため、画面を共有端末に残さず、使用後に閉じる。
