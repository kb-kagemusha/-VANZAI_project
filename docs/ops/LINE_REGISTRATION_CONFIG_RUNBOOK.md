# LINE登録の追加設定（検証用）

DEC-032/033の承認・紐付けルールを変更しない。2026-10-12のユーザー許可により検証入口を有効にする。一般公開と実在者情報の取得は未承認。今後の変更は毎回ユーザーへ確認する。

APIの起動時に `/var/www/vanzai/line-registration-config.json` を読む。既存の `.env` は編集・表示しない。追加設定はgit管理外で、パーミッションは0600とする。APIの各ワーカーは同じ設定を読み込むため、変更後はAPI再起動が必要。

```json
{
  "LINE_LOGIN_CHANNEL_ID": "LINEログインチャネルのID",
  "LINE_LIFF_ID": "LIFFのID",
  "LINE_WORKER_REGISTRATION_ENABLED": true
}
```

3キー以外や不正な型・形式は許可しない。秘密情報は格納しない。設定ファイルがない場合は既存の環境変数の動作を維持する。ファイルが存在する場合は、この3項目に限り追加設定を優先する。

確認は `/api/health` と `/api/line/registration/entry` を使用する。後者の `enabled` と `liff_id` を確認したあと、開発中チャネルに権限のあるLINEアカウントで「登録」を送信し、ボタンから架空情報を入力する。実機のログイン・権限同意は本人が行う。

入口を閉じる場合は、ユーザーの許可を受けて追加設定の `LINE_WORKER_REGISTRATION_ENABLED` を false にし、APIを再起動する。申請、稼働者、既存のLINE紐付けは削除しない。

今回の変更は設定読み込みのみで、業務データの更新・新規の業務監査ログは発生しない。既存のWebhook受付結果・申請送信・審査の監査は従来どおり。
