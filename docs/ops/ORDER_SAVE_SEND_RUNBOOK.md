# 発注依頼書の保存と送付（0.59.0）

依頼書は、先に「保存」し、あとから別の操作で「送付」する。保存だけでは誰にも送られない。

1. 「新規の依頼書を作成」で、作成のしかた「保存のみ」（初期）を選んだまま内容を入力し、「保存」を押す。送付の欄は出ない。保存した依頼書は、見出し下の「保存した依頼書を呼び出す」から開いて直したり、「送付へ進む」で送れる。送付先・期限の案内は未定でも保存できる。一覧には「保存済み（未送付）」と出る。
2. 日程などが変わったら、一覧から開いて直し、「保存」を押す。送付するまでは同じ版を直接直せる（版は増えない）。
3. 送るときは、一覧の「送付へ進む」か、開いた依頼書の「送付へ進む」を押す。内容を保存したあと「送付の設定」が開く。
4. 「送付の設定」で、回答の期限（日付・時刻）と送付先（最大40人）、必要なら個人別の不参加日を決め、「PDFを確認する」を押す。期限が過ぎている、または送付先がないと進めない。
5. PDFを確認し、「今すぐ送付する」を押す。このときPDF・送付先・版が確定し、公式LINEで紐付け済みの人へ送られる。送るタイミングは押した時点で、予約送信はない。
6. 送付したあとに内容を変えるときは「変更を作成」で変更版を作る（上書きしない）。変更版も、保存→送付は別の操作。

## 一覧の状態

- 保存済み（未送付）：保存だけ、または確定したが1人にも送信が受け付けられていない。
- 一部送付済み：送れた人と、未送・失敗・結果不明の人がいる。残りの送付を忘れない。
- 送付済み：全員に送信が受け付けられた。取消は「取消」。
- 一覧条件で絞り込める。確定済みで未送付のまま残った旧い依頼書は、開いて従来の「送付する」で送る。

## 変えないこと

- テスト／正式の区別、テストの回答・送信履歴を正式版へ持ち込まない決まり。確定後の本文は上書きしない。
- 監査は既存の確定・送信の記録を使う。正本：DEC-143。検証：test_api_order_requests.py、calendar-order-participation-ui.spec.ts。
