# 依頼書の金額確定・依頼元別月次請求

仕様: DESIGN_SPEC_v0.3 §11.4 / DEC-074。全体管理者（admin）のみ利用可能。

## 日々の金額確定

1. サイドメニュー「依頼書の金額確定」を開く。赤い数字は正式・確定済みの最新依頼書のうち金額未入力の件数。下書き・テスト・取消・削除・置換済み旧版は対象外。
2. 文書番号で内容を確認し「請求金額を確定」を押す。請求先、請求月、依頼書1件の税抜請求総額を入力する。稼働者への支払単価からは計算しない。
3. 月をまたぐ依頼も指定した請求月に全額計上する。請求月は初期未選択。0円は入力済みとして扱う。
4. 金額・請求先・請求月を変更する場合は変更理由を入力する。確定履歴は追記され、上書きされない。

## 月末の請求書作成

初回は「発行元・振込先設定」を開き、正式名称・郵便番号・住所・登録番号・振込先・支払期限を確認する。正式名称と住所の初期値はユーザー指定の株式会社VANZAI／〒116-0002 東京都荒川区荒川1丁目39-11 東京アルバタワー1703。登録番号・振込先・支払期限は未指定のため空欄。任意項目の空欄はPDFに記載しない。保存しても作成済み帳票は変わらず、新しい下書きに反映する。

1. 未入力一覧を確認し、その月の対象依頼の金額をすべて確定する。
2. 「依頼元別の月次請求書」で請求月を選び「月次請求書を作成」。請求先と請求日を選ぶ。金額確定済みの対象だけを集約して下書きを作る。
3. 明細・税抜小計・消費税・合計・PDFを確認する。消費税は依頼元ごとの月次税抜小計×10%、円未満切捨て。税率・丸め・請求先名と住所・明細金額は帳票に保存される。
4. 誤りがあれば「下書きを取り消す」で理由を記録し、必要な金額を修正して再作成する。旧下書き・旧明細・旧PDFは残り、版が増える。
5. 正しければ「確認して発行する」。確認ダイアログを経て発行済みとなる。保存済みPDFは「明細・PDFを確認」から開ける。取引先への送信は自動実行しない。

## 運用上の境界

- 請求書作成時点の明細が正本。下書き作成後の追加金額や元依頼の改訂・取消を検出した場合は発行を停止する。下書きを取消してまとめ直す。
- 同じ依頼系列を複数の請求書へ二重に入れない。修正版を確定した場合、旧金額を自動継承せず再確認する。旧版が請求書に入っている場合は、その請求書を確認する。
- 既存の実績ベース請求とは明細の対応関係がないため、同一請求先・同一請求月に両経路の請求書を作る操作を相互に拒否する。見積書は対象外。既存請求書がある月は請求経路を確認する。
- 発行済みの訂正・追加請求・取消はこの画面では行わない。発行済みの金額・明細・PDFを変更したり、DBを直接書き換えたりしない。訂正伝票の運用は別途決定が必要。
- 既存の実績会計・稼働者支払・締め状態とは独立。既存の実績請求一覧へ自動計上されない。月次作業ではこの画面の請求書一覧も確認する。
- 発行元・振込先・登録番号・支払期限は全体管理者が設定から変更可能。作成時の設定revisionと内容を請求書に保存するため、移転・振込先変更で過去の帳票は変わらない。支払期限・条件は自由文（例：請求月の翌月末まで）で、日付の自動計算はしない。
- 保管PDFが失われた場合は自動再生成せず404とする。発行時のPDFをストレージのバックアップから復元する。

## 記録・権限と保守

- `order_billing_amounts` は版別の追記履歴、`order_billing_invoice_lines` は金額明細正本。請求ヘッダーは集計値、請求先・税率はスナップショット。
- `order_billing_tax_rules` の `standard-10-floor-v1` をmigrationで初期設定。既存帳票の税率を後から解決し直さない。
- `order_billing_issuer` は発行元設定とrevisionを保持。競合更新を409で拒否し、設定変更は`order_billing_issuer_updated`へ変更前後を記録する。
- 監査: `order_billing_amount_confirmed` / `order_billing_invoice_created` / `order_billing_invoice_issued` / `order_billing_invoice_draft_cancelled`。全体管理者以外の監査検索ではこれらの記録を返さない。
- Migration `20261023c001` は新規5テーブル・制約・税ルール・発行元初期値の追加のみ。既存依頼・実績・請求・支払を移行・削除しない。
- 検証: `tests/test_order_billing.py` と `apps/admin-web/e2e/order-billing-ui.spec.ts`。発行後固定・小計課税切捨て・版変更・二重計上・全体管理者限定を確認する。
