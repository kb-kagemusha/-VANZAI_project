# マスタ追加・クライアント連絡先・内部発注元（0.46.1）

## マスタ一覧
「表示切替」を選ぶと一覧を表示する。新規登録は右側の「新規追加」を押す。入力・登録はポップアップで行い、保存成功後に一覧へ戻る。各切替ボタンは異なる縁色で、現在選択中は下線と強調も付ける。

## クライアントの電話と複数担当者
クライアントの新規追加で会社電話、担当者1の氏名/電話/メールを入力する。「担当者を追加」で2人目以降を入力できる。会社・全担当者を一括保存する。担当者に電話やメールを入力した場合は氏名も必要。会社電話/担当者電話は任意で、20文字まで。

既存会社は一覧の「担当者管理」を開く。ポップアップで会社電話を更新し、担当者一覧を確認する。「担当者を追加」で担当者を増やせる。各担当者の編集では電話・メールも変更できる。旧単独担当者は移行で担当者一覧へ補完するが、旧項目と既存の担当者は残す。同名担当者がある場合、その電話を上書きしない。

## 発注依頼書の発注元（内部管理）
「発注元」でクライアントを選び、「担当者（発注元）」でその会社の有効な担当者を選ぶ。会社を変更すると担当者の選択が解除される。未設定のまま下書き/確定を行うこともでき、旧依頼書を強制的に書き換えない。

会社名・担当者名・電話は内部専用項目。稼働者へ送る本文、LINE、PDF、公開スナップショットへ含めない。「運営側の連絡担当者」は従来の帳票用担当者で、発注元の担当者とは別。内部担当者をこの欄へ自動転記しない。

選択時の会社/担当者情報を版へ保存する。同じ参照での再保存は保存済み情報を保持する。無効・削除済みの旧担当者でも保存済み参照は履歴として保持するが、新しく選ぶことはできない。参照を変えると現行マスタから取得する。確定後の内部情報は変更不可で、改訂/変更の新しい版で修正する。旧版は固定する。

## 移行と監査
20261014a001は会社電話、依頼書の内部発注元FK/JSON、担当者に会社が必要なCHECKを追加する。旧担当者の補完は追加だけで、旧データを削除しない。既存の本文・PDF・金額は変更しない。

会社・担当者作成、会社電話/担当者編集、内部発注元の変更を監査へ記録する。内部発注元の監査値はIDのみ、電話の監査は変更フィールド名のみとし、電話番号を複製しない。
