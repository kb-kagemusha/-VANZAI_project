# 遅刻・キャンセル記録と支払時の確認

目的：ディレクターなど現場責任者から届いた報告を、本人・イベント・稼働日に結び付け、月次の支払判断で見落とさない。

## 記録

1. サイドメニュー「運用」→「遅刻・キャンセル記録」を開き、稼働月を選ぶ。
2. 「記録を登録」からイベント・稼働日・稼働予定者を選ぶ。依頼書を受諾して生成された予定が対象。取り消した過去の予定も選べる。
3. 遅刻／キャンセル・中止、本人都合／台風・天候／その他、理由と報告者を入力する。遅刻時間は分で記録（2時間＝120）。登録者と日時は自動保存する。
4. 誤記は取消理由を付けて「記録を取り消す」。履歴は残る。正しい内容を新規登録する。同一イベント系列・本人・日・種別の有効な記録は1件。

正式とテストは排他切替。テストの記録は正式の支払注意事項へ出ない。稼働日が月をまたぐ場合は対象月を切り替えて登録する。

## 月次支払

- 支払一覧の対象月は稼働月として照合する。支払日が翌月でも報告は元の稼働月に表示する。
- 画面上部の注意事項は、その稼働月の正式な有効記録すべて。支払明細未生成の本人都合キャンセルも見落とさないため含める。
- 稼働者への各支払行は、合計額の前に「支払前の注意事項」を表示する。開くと同じ本人・稼働月の全イベントの記録を表示し、その下に当該支払明細の合計を表示する。
- 支払明細生成のポップアップでも、稼働者を選ぶと月次注意事項を表示する。
- 現行の実績由来支払は案件別の明細を持つ。依頼書由来イベントと実績由来案件の対応は未確定なので、名前で同一案件と推測しない。本人・月の全イベントの報告として表示し、担当者が当該支払の対象案件と照合する。今回、月次合算や支払計算方式は変更しない。
- 記録が多い場合は50件ごとに次ページを確認する。取得失敗は「注意事項なし」と扱わない。

## 支払判断

- ディレクターの日給は依頼ごとに指定。早出設営は都度指定の1回固定報酬（条件別依頼書と支払自動連携は今回対象外）。
- 受諾済み報酬は保証する。台風などによる中止は日給・早出設営の固定報酬を満額支払う。
- 病気・怪我など本人都合の勤務全体キャンセルは当日の支払対象外。本人都合の早出だけのキャンセルは早出分を支払わない。今回のキャンセル記録は当日の勤務全体が対象。早出だけのキャンセルは備考に範囲を明記し、別途担当者へ確認する（専用の範囲指定・自動計算は未実装）。
- 遅刻時の減額方法は未決。時間比例の自動減額をしない。
- 登録・取消は確認資料だけを更新し、稼働予定・実績・支払金額・請求額・確定PDF・締めを変更しない。支払額への反映は既存の確認・訂正手順で別途行う。
- 締め後に受けた報告も記録できるが、締め済み金額は変わらない。

## 権限と監査

- 全体管理者はすべて操作可。未設定の運用担当は閲覧・登録・取消、未設定の経理担当は閲覧。
- 保存済みの役割権限設定は自動拡張しない。必要ならID・権限管理で「遅刻・キャンセル記録：閲覧／編集」を付与する。
- 支払閲覧権限がある管理側ユーザーは支払用注意事項を閲覧できる。稼働者ログインから他人の記録を参照できない。
- `attendance_note_recorded` / `attendance_note_voided` に対象・実行者・理由を記録。元の報告内容は上書きせず取消履歴を残す。
- 現段階は運営による手入力。LINEでの報告受付は将来追加する。
